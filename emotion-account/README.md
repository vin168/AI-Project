# 情绪账本 - 微信小程序

一个以「情绪」为核心的轻量记账工具，通过记录消费时的情绪，降低记账门槛，帮助用户洞察消费心理，实现理性消费。

## 项目特点

- **情绪记账**：记录消费时的情绪（开心犒劳、心疼肉痛、冲动后悔、无奈必需、治愈安慰、值得投资）
- **轻量设计**：简洁的界面，温柔治愈的视觉风格
- **数据可视化**：按情绪、分类、日期多维度统计
- **月度报告**：自动生成月度情绪消费报告，可保存分享
- **隐私保护**：数据本地存储，登录后可云端备份

## 功能模块

1. **首页**：消费流水展示 + 快速记账入口
2. **记账页**：3步快速记账（金额 → 分类 → 情绪 → 备注）
3. **统计页**：按情绪/分类/日期查看消费数据
4. **我的页面**：预算设置、月度报告、数据管理、设置

## 开发环境要求

- 微信开发者工具（最新版本）
- 小程序 AppID（可在微信公众平台注册获取）
- 基础 JavaScript/HTML/CSS 知识

## 快速开始

### 1. 导入项目到微信开发者工具

1. 打开微信开发者工具
2. 点击「导入项目」
3. 选择 `D:\emotion-account` 目录
4. 填写你的小程序 AppID（如无，可使用测试号）
5. 点击「导入」

### 2. 项目结构

```
emotion-account/
├── app.js              # 小程序逻辑
├── app.json            # 小程序配置
├── app.wxss            # 全局样式
├── project.config.json # 项目配置
├── sitemap.json        # 搜索索引
├── images/             # 图片资源
├── pages/              # 页面目录
│   ├── index/          # 首页
│   ├── add/            # 记账页
│   ├── stats/          # 统计页
│   └── profile/        # 我的页面
└── README.md           # 说明文档
```

### 3. 配置修改

1. 打开 `project.config.json`，将 `appid` 替换为你的小程序 AppID
2. 如果需要，可以在 `app.json` 中调整颜色主题和页面配置

### 4. 运行项目

1. 在微信开发者工具中点击「编译」
2. 预览小程序界面
3. 使用模拟器进行功能测试

## 开发说明

### 数据存储

- 使用微信小程序的 `wx.setStorageSync` 和 `wx.getStorageSync` 进行本地存储
- 登录后可使用云开发功能进行云端备份
- 数据结构在 `app.js` 的 `globalData` 中定义

### 核心功能实现

#### 情绪标签系统
- 6种固定情绪标签，不可自定义（MVP版本）
- 每种情绪有对应的颜色和表情符号
- 情绪选择影响统计和月度报告

#### 月度报告生成
- 每月1号自动生成上月报告
- 基于情绪数据分析消费行为
- 可保存为图片分享

#### 预算预警系统
- 设置月度预算后自动计算进度
- 当支出超过预算80%时提醒
- 冲动消费超过40%时提示

### 页面说明

#### 首页 (`pages/index/index`)
- 显示今日支出/收入总额
- 展示今日主情绪
- 按时间倒序显示消费流水
- 悬浮记账按钮

#### 记账页 (`pages/add/add`)
- 金额输入（支持正负数切换）
- 分类选择（8个默认分类）
- 情绪选择（6种情绪）
- 备注输入（可选）

#### 统计页 (`pages/stats/stats`)
- 按情绪查看（饼图+进度条）
- 按分类查看（饼图+进度条）
- 按日期查看（日历视图）
- 时间筛选（今日/本周/本月/自定义）

#### 我的页面 (`pages/profile/profile`)
- 用户登录/信息
- 月度预算设置
- 月度报告查看/生成
- 数据管理（备份/导出/清除）
- 设置（提醒/关于/反馈）

## 注意事项

### 图片资源
- 项目中包含占位图片文件，实际使用时需要替换为真实图片
- 建议使用以下尺寸：
  - Tab图标：81×81px
  - 头像：200×200px
  - 分享封面：5:4 比例

### 权限配置
- 需要用户授权获取头像和昵称
- 云备份功能需要开通云开发
- 导出功能需要云函数支持

### 兼容性
- 支持微信小程序基础库 2.10.0 及以上
- 适配主流 iOS 和 Android 设备
- 响应式布局，支持不同屏幕尺寸

## 常见问题

### Q: 如何修改主题颜色？
A: 在 `app.wxss` 的 `:root` 中修改 CSS 变量值

### Q: 如何添加新的消费分类？
A: MVP版本不支持自定义分类，需要修改 `app.js` 中的 `categories` 数组

### Q: 如何测试月度报告功能？
A: 在「我的页面」点击「生成本月报告」，需要先有本月记账记录

### Q: 数据如何备份到云端？
A: 需要先登录，然后在「我的页面」点击「云备份」
